# Boho Cafe playful scrapbook website

## Goal
Build a single-page, mobile-first café experience that feels handmade, cozy, colorful, and delightfully chaotic rather than polished or corporate.

## What I’ll build
- A bubbly café identity and sticky playful navigation with a prominent WhatsApp action.
- An oversized scrapbook hero with an authentic café snapshot, doodles, stickers, floating labels, and a strong visit/menu action.
- A warm owner-note section introducing the pet-friendly, games-and-match-day atmosphere.
- A hand-drawn menu board with illustrated category icons, dotted price leaders, and sample café favorites.
- A tilted polaroid memory collage using the custom café imagery already created.
- A cheerful visit section with Dam Road location details, hours, contact actions, and the required portfolio disclosure.
- Responsive layouts that retain stickers, doodles, and oversized touch targets on phones.

## Motion and interactions
- Gentle floating steam and decorative doodles.
- Scroll reveals that pop and rotate into place.
- Wiggling links and squishy buttons on hover/tap.
- A small heart/star burst when the WhatsApp action is pressed.
- Polaroids that straighten and lift on hover.
- Reduced-motion support for visitors who request it.

## Technical details
- Keep everything on the existing home page.
- Define the complete warm cream, berry, coral, sage, mustard, and deep-brown system in global theme tokens.
- Use friendly rounded and handwritten web fonts loaded from the page head.
- Use reusable local sections and the existing button component, adding café-specific variants.
- Use semantic colors throughout and update the page metadata and favicon to match Boho Cafe.
- Use placeholder contact links where exact phone/WhatsApp details are unavailable, while clearly avoiding invented contact information.
- Verify the finished page at desktop and phone sizes, including interactions and overflow.
